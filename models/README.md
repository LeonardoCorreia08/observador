# Modelos

Os pesos treinados não são incluídos por padrão. Para cada modelo, registe:

- nome e arquitetura;
- origem dos pesos iniciais;
- dataset e versão;
- commit do código;
- configuração de treino;
- métricas no conjunto de teste;
- licença e restrições de redistribuição;
- caminho/URL do artefato e hash SHA-256.
