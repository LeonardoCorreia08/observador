# Dados

Os datasets não são incluídos neste repositório. Registe a origem, licença, versão, data de obtenção, número de imagens por split e procedimento de anotação em `docs/data_card.md`.

Não publique dados privados, imagens sem autorização ou dados pessoais. Se os dados forem extraídos de vídeos, faça a divisão por vídeo/sequência para evitar vazamento entre treino e teste.
